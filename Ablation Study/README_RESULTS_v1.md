# 排名中心恢复：消融实验代码与验证结果 v1

记录日期：2026-11-06（Asia/Shanghai）。实验目录：`outputs/ablation_core_v1`；报告批次：`validation_20261106_200925`。

本说明整理已完成的核心消融实验及代码，供 GitHub 展示与复现。**完整模型在宏平均 Kendall、RBO 上优于 Borda 等部分基线，但仍落后于 MC4 和 Copeland。显式统计信息的贡献较清楚，部分分支可能存在冗余。**

本文件为新增文档，不覆盖原运行说明、源码、数据或权重。详细接口见 [README.md](README.md)；其中“正式消融尚未运行”为初次交付时的状态，核心组当前状态以本报告为准。这里是验证集开发结果，不是最终独立测试结论。

## 1. 研究目标与完成范围

给定多个带噪完整排名，利用对应中心排名进行监督训练，恢复潜在中心。重点是噪声恢复与少量榜单场景，不以最大化无权 Kemeny 求解能力为目标。真实大学榜单的“共识”是否可以表示为唯一中心，需要另行定义和检验。

本轮完成 A0–A5 六个配置，每个使用42、43、44三个训练种子，共18次独立训练。验证使用500个中心，每中心三种噪声、四种观察数量，共6000组输入/模型。它们不是6000个独立中心；相同中心跨条件和种子复用。18个任务均为 complete，216条条件×种子汇总记录每条均含500个样本。

位置机制、训练观察数量、训练噪声分布组已有代码接口，但本报告不包含这些扩展组结果，也不包含正式独立测试结果。

### 核心消融配置

| ID | 改动位置及内容 | 检验问题 |
|---|---|---|
| A0 | 完整 v3 路径，两个位置机制关闭 | 重新训练的对照 |
| A1 | rank_skip 输入置零，保留 summary_map | 统计量直达输出的额外作用 |
| A2 | encode 不加入 summary_map，同时关闭 rank_skip | 显式统计通道的作用 |
| A3 | encode 前将每个对象的名次替换为均值重复 m 次 | 平均名次之外的信息价值 |
| A4 | encode 不使用 observation_map 输出，保留统计通道 | 学习式观察特征是否超出显式统计量 |
| A5 | 跳过编码器注意力残差，保留 FFN 和全部解码器 | 编码器对象交互的贡献 |

统计量包括归一化名次均值、标准差、最小值、最大值、倒数名次均值及 log(1+m)。A2 仍可能从学习分支学出统计信息；A3 没有直接调用 Borda；A4 仍含 Transformer；A5 仍有解码器交互。

### 指标及统计定义

- Kendall 为逆序对数除以 N(N−1)/2，越小越好，不是相关系数。
- RBO distance 使用 p=0.9 的有限深度归一化定义，越小越好，不是外推 RBO 或相似度。
- 辅助指标为完整恢复率、前10集合重合率、前10对象平均绝对位移。
- 主结果对12条件等权平均，再平均三个种子；种子SD为样本标准差。
- 配对 bootstrap 重采样2000次，分别重采样种子与中心，方法间共享中心索引，保留同中心不同条件的关联。
- 五个预设核心 Kendall 对比展示99%区间；其他95%区间不能一概视为经过多重检验校正。验证集参与选权重，所有区间仍是探索性证据。

## 5. 模块贡献分析

以下差值为“消融变体−A0”，正值表示移除后变差。

| 对比 | Kendall 差值 | Kendall 99%区间 | RBO 差值 | RBO 95%区间 |
|---|---:|---|---:|---|
| A1−A0 | +0.00000036 | [−0.00001701, +0.00001837] | +0.00007578 | [−0.00016871, +0.00031038] |
| A2−A0 | +0.00042703 | [+0.00037633, +0.00047769] | +0.00127213 | [+0.00093605, +0.00162024] |
| A3−A0 | +0.00053986 | [+0.00047923, +0.00059279] | +0.00235361 | [+0.00183925, +0.00287280] |
| A4−A0 | +0.00001193 | [−0.00001864, +0.00004041] | +0.00009886 | [−0.00017772, +0.00037121] |
| A5−A0 | +0.00009787 | [+0.00005660, +0.00013892] | +0.00026832 | [−0.00013753, +0.00069655] |

1. **显式统计通道有贡献。** A2 明显变差，A1 接近 A0，支持统计量经隐藏层进入模型的路径有价值。但尚未逐项消融均值、标准差、极值等，不能归因于某一统计量。
2. **统计直连可能冗余。** A1 未显示明确损失，可以作为简化候选；区间跨0不等于已经证明等效。
3. **均值之外的输入有价值。** A3 两项距离变差，支持保留更丰富的观察信息。
4. **学习式观察分支的额外收益不明确。** A4 接近 A0，提示统计特征可能已覆盖当前任务主要有效信息；这仍是解释假说。
5. **编码器注意力有较小的 Kendall 收益。** A5 Kendall 距离约增加0.93%，但 RBO 区间跨0。N=50 时该 Kendall 差值约对应0.12个逆序对/中心，统计证据与实用幅度应分开解释。

移除模块也改变有效容量和优化过程。本轮衡量固定协议下的模块总体作用，不能完全隔离参数量、函数形式与训练时长。

### A3 与 Borda 的逐样本一致性

逐条核对所选权重的验证预测后发现：种子42、43、44各自均有 **6000/6000** 组输入的完整输出排名与 Borda 一致，包括最终并列处理后的排列。这解释了 A3 的跨种子指标标准差接近0。

三个 A3 任务均选择第1轮权重，第11轮早停。该事实不意味着代码跳过训练，也不证明 A3 对任意输入数学等价于 Borda；它说明本轮所选模型在当前验证输入上表现一致。结合 A4 接近 A0，完整模型的收益可能主要由显式统计通道承载，但仍需进一步验证。

## 8. 运行与复现命令

在项目根目录的 PowerShell 中逐步执行，每步成功后再继续。下面使用新输出目录，避免覆盖本次已完成实验；需要已有兼容 v3 dataset.pt、PyTorch 和 NumPy。

```powershell
Set-Location 'D:\Github_Project\Deng'
$py = 'D:/Anaconda/envs/Pytorch/python.exe'
$cli = 'D:/Github_Project/Deng/Ablation Study/run_ablation.py'
$study = 'D:/Github_Project/Deng/outputs/ablation_core_reproduction_v1'
$dataset = 'D:/Github_Project/Deng/outputs/v3_run_ad482c219a0944858edc0efdb7b0f574/data/dataset_20261106_121433_096724_9867d22d/dataset.pt'

& $py -B 'Ablation Study/tests.py'
& $py -B $cli prepare --study $study --dataset $dataset --group core --seeds 42 43 44 --epochs 50 --patience 10 --batch-size 32 --lr 0.0001
& $py -B $cli run --study $study --device cuda --execute
& $py -B $cli baselines --study $study --execute
& $py -B $cli summarize --study $study --phase validation --bootstrap 2000
```

prepare 要求 study 尚不存在；run 无 --execute 仅预览。成功任务会校验后跳过；失败或中断任务没有自动 checkpoint 续训，需要先核查状态。不要并发启动同一实验。准备后改变本目录 Python 文件会触发源码指纹保护；新增 Markdown 不影响指纹。

### 独立最终测试接口

本报告未执行或汇报正式最终测试。先锁定方案并完成对应 study 的训练，再使用以下接口；$study 应指向最终选定的已完成实验。

```powershell
& $py -B $cli freeze-final --study $study --samples 1000 --data-seed 2026111601 --robustness
& $py -B $cli make-final-test --study $study --execute
& $py -B $cli evaluate-final --study $study --device cuda --execute
& $py -B $cli summarize --study $study --phase final --bootstrap 10000
```

robustness 增加两种预设未见阶段参数，另行报告，不混入原12条件主宏平均。历史中心扫描只覆盖可访问数据；项目外或自定义文件名数据需使用 --exclude 补充。不能核查已删除且无存档的中心。最终测试不用于调参或重抽样。

若做5种子确认，需新 prepare 时指定42/43/44/45/46；不能向已冻结3种子计划追加，也不自动导入其他 study 的已有任务。
